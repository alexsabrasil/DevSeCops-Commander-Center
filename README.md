# 🛡️ DevSecOps Command Center

Dashboard interativo desenvolvido como experiência prática de aprendizagem em **DevSecOps**, explorando conceitos de segurança integrada ao ciclo de desenvolvimento de software.

O projeto foi criado com apoio do **Gemini Canvas**, a partir do desafio de experimentar recursos de IA na construção de uma aplicação interativa.

## 🚀 Sobre o projeto

O DevSecOps Command Center simula visualmente um pipeline CI/CD com práticas de segurança incorporadas desde as primeiras etapas do desenvolvimento, seguindo o conceito de **Shift Left Security**.

O dashboard apresenta as etapas:

- 🔨 Build
- 🧪 Tests
- 🔐 SAST
- 📦 Dependency Scan (SCA)
- 🚀 Deploy

Também inclui métricas de segurança, auditoria de políticas e um terminal interativo para explorar comandos relacionados ao pipeline.

## 🔐 Conceitos explorados

- SCA
- SBOM

- OWASP

## 🛠️ Tecnologias

- HTML5
- CSS
- JavaScript
- Tailwind CSS
- Gemini Canvas

O dashboard também representa, de forma educacional e simulada, ferramentas e tecnologias utilizadas em ambientes DevSecOps, como Docker, Kubernetes, Semgrep, SonarQube, Trivy, OPA Gatekeeper, Gitleaks e Cosign.

## 🎯 Objetivo

O objetivo deste projeto é transformar conceitos estudados em DevSecOps e Segurança da Informação em uma experiência visual e interativa, facilitando a compreensão de como controles de segurança podem fazer parte de um pipeline de desenvolvimento.

> Segurança não é apenas a última etapa do pipeline.  
> **Shift Left. Secure by Design.**

## 📌 Observação

Este projeto possui finalidade **educacional e demonstrativa**. As execuções, métricas, análises de vulnerabilidades e resultados apresentados no dashboard são simulações e não representam um ambiente de produção real.
